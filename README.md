# CPLA 1er D - Coach Personnel de Lutte contre l'Abandons (1ère D Togo)

CPLA 1er D est une application web progressive (PWA) conçue pour accompagner les élèves de Première D au Togo dans leur réussite scolaire et la préparation de leur examen.

## 🚀 Fonctionnalités

- **Tableau de Bord Intelligent** : Suivi de la moyenne estimée et progression globale.
- **Super Scan IA** : Scannez vos cours papier pour générer instantanément des résumés, des supports d'apprentissage actif et des exercices de validation.
- **Roadmap Personnalisée** : Planning d'étude généré par IA en fonction de vos objectifs et de vos disponibilités.
- **Programme Complet** : Accès structuré à toutes les matières (Maths, PC, SVT, Français, etc.) avec suivi par chapitre.
- **Analytiques** : Visualisation des efforts fournis et du temps d'étude.
- **Mode Hors-ligne** : Accès à vos données même sans connexion internet grâce au cache local et à la technologie PWA.

## 🛠️ Stack Technique

- **Frontend** : React 19, Vite 6, TypeScript, Tailwind CSS v4.
- **Backend** : Firebase (Auth, Firestore).
- **IA** : Google Gemini API (Modèle 2.0 Flash).
- **Mobile** : Capacitor.js (pour Android & iOS).
- **Déploiement** : GitHub Actions pour le build mobile automatique.

## 📱 Installation

L'application peut être installée sur votre téléphone comme une application native :
1. Ouvrez l'URL de l'application dans votre navigateur.
2. Cliquez sur "Ajouter à l'écran d'accueil" ou "Installer l'application".
